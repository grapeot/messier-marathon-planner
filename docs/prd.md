# PRD：梅西耶马拉松观测规划工具

## 目标

为给定地点和日期，推荐使用 ZWO SeeStar S30 Pro / S50 拍摄梅西耶天体的最佳方案。输出包含排名、曝光时间建议、可视化图表和可公开验证的交叉对照链接。

## 用户场景

1. 天文爱好者在观测前想快速知道今晚哪些梅西耶天体最值得拍
2. 需要对排名结果进行独立验证，确认计算的可靠性
3. 需要在 S30 Pro 和 S50 之间做出设备选择

## 成功标准

- 94/110 个梅西耶天体正确计算可见窗口（太阳 < -12° 且目标 > 15°）
- Top 5 推荐目标的交叉验证链接可在 Stellarium Web 等公开工具中重现
- 面亮度和曝光时间估算与设备参数一致
- 报告可在 30 秒内重新生成
- 仓库自带可安装 skill，用户可把 GitHub 链接交给 AI agent 复用这套规划流程

## 非目标

- 不是实时控制系统（不直接驱动望远镜）
- 不考虑云量、seeing、光污染等天气因素
- 不替代 Seestar App 内置的天体推荐功能
