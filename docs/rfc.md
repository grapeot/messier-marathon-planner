## 关键技术决策

### 0. 主验证图

`plot_top10_sun_altitude()` 把太阳高度和 Top10 推荐目标高度画在同一张图上。横轴使用北京时间，纵轴使用高度角。太阳 -12° 线和目标 15° 线作为可见性阈值。

这张图承担人工 sanity check 的职责：推荐目标应该在暗夜窗口内达到较高高度，而且目标之间的最佳时间应该覆盖整个夜晚，而不是都挤在同一小时。

### 1. 可见性判定

- 太阳高度 < -12°（航海晨昏）：Seestar 的 stacking 模式在航海晨昏已可正常工作，比天文晨昏（-18°）更宽松
- 目标高度 > 15°：低于此角度大气消光显著且经纬仪跟踪精度下降

### 2. 面亮度计算

平均面亮度 (mag/arcmin²) = V_mag + 2.5 × log₁₀(面积[arcmin²])

面积 = π × (长轴/2) × (短轴/2)

转换为 mag/arcsec²：加 8.89

**注意**：这是平均面亮度。星系的核心区域和星云的 HII 区比平均值亮很多。因此面亮度适合做**相对排序**而非直接用于曝光计算。曝光公式中加入了类型系数来部分补偿。

### 3. 综合评分权重

```
综合 = 0.30×高度 + 0.35×亮度 + 0.10×时长 + 0.25×FOV匹配
```

权重理由：
- 亮度和 FOV 匹配占 60%：直接影响拍摄质量
- 高度占 30%：大气消光和跟踪稳定性
- 时长权重仅 10%：Seestar 自动跟踪，只要窗口够拍即可

### 4. 曝光时间公式

```
曝光(分钟) = 类型系数 × 基准 × (2500/口径²) × 10^(0.4×(面亮度-20))
```

基准：50mm 口径 + 面亮度 20 mag/arcsec² 约需 10 分钟。

类型系数：OC=0.3, GC=0.6, NB=0.8, PN=0.7, GX/EGX/SGX/IGX=1.5, SR=1.0, AST=0.2, BIN=0.1

### 5. 目标过滤

排除 BIN（双星, 如 M40）和 AST（星群/恒星云, 如 M24, M73），因为它们不适合天文摄影。
